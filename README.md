# Home Lab Infrastructure

A public engineering portfolio documenting my self-hosted Linux/ZimaOS and Docker home lab.

> Looking for production API keys? `lol_u_thought`.

## Technologies
Docker, Jellyfin, Sonarr, Radarr, qBittorrent, Gluetun/WireGuard, Tailscale, Pi-hole, and Network UPS Tools (NUT).

## Engineering focus
Container orchestration, private networking, DNS filtering, VPN isolation, power management, troubleshooting, and operational documentation.

## Project status
- **Implemented:** Core Docker services, Tailscale remote access, Pi-hole DNS filtering, Gluetun connectivity, and initial NUT monitoring.
- **In progress:** Storage migration, VPN isolation verification, and shutdown validation.
- **Planned:** Bazarr, Tdarr, and backup restoration testing.
